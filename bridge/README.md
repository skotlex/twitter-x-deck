# 이미지 번역 브리지

사진 속 글자를 번역하는 기능은 이 PC 에 깔린 `codex` · `claude` 명령을 빌려 씁니다.
확장은 파일도 프로세스도 만질 수 없어서, 그 사이를 잇는 작은 서버가 하나 필요합니다.

별도 API 키가 필요하지 않습니다. 두 명령이 이미 로그인해 둔 **구독 계정**을 그대로 씁니다.

## 실행

```bash
npm run bridge
```

뜨면 콘솔에 열쇠가 한 줄 찍힙니다. 덱의 **설정 › 번역** 에 그 값을 붙여넣으면 연결됩니다.
열쇠는 `bridge/.bridge-token` 에도 남아 있고, 저장소에는 올라가지 않습니다.

포트를 바꾸려면 `XDECK_BRIDGE_PORT` 를 지정합니다 (기본 8765). 덱 설정의 포트도 같이 맞춰야 합니다.

## 두 엔진의 차이

| | codex | claude |
| --- | --- | --- |
| 결과 | 번역된 **이미지** | 원문과 번역 **텍스트** |
| 걸리는 시간 | 30초 ~ 1분 남짓 | 수 초 |
| 어울리는 사진 | 포스터·만화처럼 배치가 뜻을 갖는 것 | 대부분의 스크린샷과 짧은 문구 |

`claude` 는 이미지를 만들지 못합니다. 번역된 그림이 필요하면 `codex` 를 고르세요.

`codex` 가 다시 그린 이미지는 원본을 그대로 둔 채 글자만 바꾼 것이 아니라 새로 그린
것입니다. 잔글씨나 로고가 뭉개질 수 있어, 덱에서는 원본과 번역본을 오갈 수 있게 해 둡니다.

## 안 될 때

- **열쇠가 맞지 않습니다** — 브리지를 다시 띄우고 새로 찍힌 열쇠를 설정에 붙여넣습니다.
- **`~/.codex/config.toml` 을 codex 가 읽지 못합니다** — 메시지에 적힌 항목을 그 파일에서
  고칩니다. 값 하나가 어긋나면 codex 는 아예 뜨지 않습니다. 남의 설정 파일을 말없이
  고치지 않으므로 브리지는 무엇이 문제인지만 알려줍니다.
- **로그인이 필요합니다** — 설정 화면의 로그인 단추를 누르면 콘솔 창이 하나 뜹니다.
  거기서 절차를 마친 뒤 **상태 다시 확인** 을 누릅니다.

## 범위

- `127.0.0.1` 에만 묶입니다. 같은 망의 다른 기기는 들어올 수 없습니다.
- `https://x.com` 에서 온 요청만 받고, 모든 요청에 열쇠를 확인합니다.
- 번역은 한 번에 하나씩 돕니다. 결과 이미지는 "무엇이 새로 생겼는지" 로 찾기 때문에
  동시에 돌리면 서로의 결과를 집어갑니다.
