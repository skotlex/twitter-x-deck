# 이미지 번역 브리지

사진 속 글자를 번역하는 기능은 이 PC 에 깔린 `codex` · `claude` 명령을 빌려 씁니다.
확장은 파일도 프로세스도 만질 수 없어서, 그 사이를 잇는 작은 프로그램이 하나 필요합니다.

별도 API 키가 필요하지 않습니다. 두 명령이 이미 로그인해 둔 **구독 계정**을 그대로 씁니다.

## 설치 — 한 번만

```
install-bridge.bat    ← 더블클릭
```

브라우저를 완전히 껐다 켠 뒤, 덱의 **설정 › 번역**에서 상태를 확인하세요.

**그 뒤로는 아무것도 띄워둘 필요가 없습니다.** 번역이 필요할 때 브라우저가 이 프로그램을
알아서 켜고, 끝나면 함께 내립니다. 터미널도, 포트도, 붙여넣을 열쇠도 없습니다.

해제는 `uninstall-bridge.bat` 입니다. `npm run bridge:install` · `npm run bridge:uninstall`
로도 같은 일을 합니다.

### 먼저 있어야 하는 것

- **Node.js**
- **`codex` 또는 `claude` CLI**, 그리고 각각의 유료 구독에 로그인
  (`npm i -g @openai/codex` · `npm i -g @anthropic-ai/claude-code`)

로그인은 설정 화면의 로그인 단추로도 시작할 수 있습니다 — 콘솔 창이 하나 뜨고, 거기서
절차를 마친 뒤 **상태 다시 확인**을 누르면 됩니다.

## 무엇을 건드리나

`HKEY_CURRENT_USER` 의 레지스트리 값과 이 폴더 안뿐입니다. 관리자 권한이 필요 없고,
해제하면 흔적이 남지 않습니다.

| 만드는 것 | 자리 |
| --- | --- |
| `com.xdeck.bridge.json` | 이 폴더. 무엇을 실행할지 적은 매니페스트 |
| `host.bat` | 이 폴더. 윈도우는 네이티브 호스트로 실행 파일만 받아, `node` 를 부르는 한 줄이 필요합니다 |
| 레지스트리 값 | `HKCU\...\NativeMessagingHosts\com.xdeck.bridge` (Chrome · Edge · Chromium · Brave · Whale) |

깔려 있지 않은 브라우저에 등록해도 해가 없습니다 — 나중에 깔면 그대로 동작합니다.

## 왜 확장이 스스로 등록하지 못하나

확장이 레지스트리에 쓸 수 있다면, 그건 임의의 확장이 브라우저로 하여금 아무 실행파일이나
켜게 만들 수 있다는 뜻입니다. 막혀 있는 것이 맞습니다. 없앨 수 있는 것은 "매번"이지
"처음 한 번"이 아닙니다.

대신 등록되지 않은 상태는 확장이 알아채고 무엇을 하라고 알려줍니다.

## 두 엔진의 차이

| | codex | claude |
| --- | --- | --- |
| 결과 | 번역된 **이미지** | 원문과 번역 **텍스트** |
| 걸리는 시간 | 30초 ~ 1분 남짓 | 수 초 |
| 어울리는 사진 | 포스터·만화처럼 배치가 뜻을 갖는 것 | 대부분의 스크린샷과 짧은 문구 |

`claude` 는 이미지를 만들지 못합니다. 번역된 그림이 필요하면 `codex` 를 고르세요.

`codex` 가 다시 그린 이미지는 원본을 그대로 둔 채 글자만 바꾼 것이 아니라 새로 그린
것입니다. 잔글씨나 로고가 뭉개질 수 있어, 덱에서는 원본과 번역본을 오갈 수 있게 해 둡니다.

## 안 될 때

- **브리지가 등록되지 않았습니다** — `install-bridge.bat` 을 실행한 뒤 브라우저를 완전히
  껐다 켜세요. 창만 닫는 것으로는 부족한 경우가 있습니다.
- **`~/.codex/config.toml` 을 codex 가 읽지 못합니다** — 메시지에 적힌 항목을 그 파일에서
  고칩니다. 값 하나가 어긋나면 codex 는 아예 뜨지 않습니다. 남의 설정 파일을 말없이
  고치지 않으므로 브리지는 무엇이 문제인지만 알려줍니다.
- **로그인이 필요합니다** — 설정 화면의 로그인 단추를 누르고, 콘솔 창에서 절차를 마친 뒤
  **상태 다시 확인** 을 누릅니다.

## 그 밖에

- 말은 표준 입출력으로 오갑니다 — 4바이트 길이 뒤에 UTF-8 JSON 한 덩이. 그래서
  `host.mjs` 는 **stdout 에 아무 것도 함부로 찍으면 안 됩니다.** 할 말은 stderr 로 보냅니다.
- 브라우저가 한 덩이를 1MB 로 끊으므로, 다시 그린 그림은 잘라서 여러 덩이로 보냅니다.
- 번역은 한 번에 하나씩 돕니다. 결과 이미지는 "무엇이 새로 생겼는지" 로 찾기 때문에
  동시에 돌리면 서로의 결과를 집어갑니다.
